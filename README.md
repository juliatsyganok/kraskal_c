
### Вариант и решение

Реализация алгоритма Краскала с представлением графа в виде списка ребер. Мое решение заключалась в том, чтобы реализовать алгоритм Краскала для поиска минимального остовного дерева. Для этого я использовала метод непересекающихся множеств.

**Таким образом были написаны следующие функции:**

* **`sort`**: это обычная пузырьковая сортировка для того, чтобы отсортировать ребра по стоимости. Это необходимо потому что алгоритм Краскала жадный и работает с минимальным ущербом то есть выбирает кратчайший из вариантов.
* **Функция определяющая группу вершины**: изначально у каждой ноды была своя собственная группа, когда ноды связываю ребром, их группа становится одинаковой. Это необходимо чтобы отследить родителя каждой ноды, чтобы избегать циклов при построении дерева.
* **`kraskal`**: сама функция. Алгоритм сортирует ребра, затем обходит каждое и проверяет алгоритмом DSU стоит ли их соединять.

### Тестирование

Мною было проведено тестирование своей программы на краевых случаях с помощью **gtest**:

1. **StandardGraph**: обычный граф для проверки базы.
2. **NegativeWeights**: проверка работы с отрицательными весами.
3. **DisconnectedGraph**: случай, когда граф не связан.
4. **SingleVertex**: граф из одной вершины.
5. **CompleteGraph**: когда все вершины связаны со всеми.
